# 差旅費報告系統

員工出差時用手機拍收據，系統自動辨識「含稅金額」與費用類別並填入差勤表單；可依月份下載報表（Excel）與收據照片（ZIP）。報表格式比照範本：每月一個標題列、明細、「N月小計」、空白列。

## 啟動
```bash
npm install
cp .env.example .env   # 依需要修改；以環境變數載入，例如：set -a; . ./.env; set +a
npm start              # http://localhost:3000
npm test
```
- 手機拍照需 **HTTPS**（或 localhost）才能開啟相機，正式部署請置於 HTTPS 反向代理後（並設 `NODE_ENV=production`）。
- 資料庫：SQLite（`DB_PATH`，預設 `data/trip.db`），使用者、差勤、**收據照片（BLOB）** 皆存於此。請定期備份該檔。
- 管理者：資料庫無管理者時以 `ADMIN_EMAIL` / `ADMIN_PASSWORD` 建立（未設密碼則啟動時印出一次性密碼）。也可 `npm run make-admin -- someone@example.com` 將員工升為管理者。

## 收據辨識
- 設定 `ANTHROPIC_API_KEY`：使用 Claude 視覺模型同時判斷類別與含稅總額（建議）。
- 未設定：使用 Tesseract.js（繁中＋英文，首次使用需下載語言檔，離線環境可設 `TESSDATA_PATH`），以關鍵字規則判斷，準確度較低。
- 辨識結果永遠可在照片下方修改金額／類別；無法判讀金額時仍會保存照片，提示手動輸入。

## 計算規則
- 交通費 = 里程數 × `MILEAGE_RATE`（預設 8）＋ 計程車 ＋ 公共交通
- 合計 = 交通費 ＋ 住宿費 ＋ 補助款 ＋ 誤餐費 ＋ 停車費 ＋ 過路費 ＋ 其他
- 某類別有收據時，欄位金額＝該類別所有收據金額加總（新增／修改／刪除收據都會重算）；補助款與里程為手動輸入。
- 時數依起迄自動計算（同日超過 5 小時扣午休 1 小時；8:30–17:30 = 1天(8h)；跨日每日 8 小時），可手動修改。

## 功能對照
員工註冊（公司、部門、員工編號、姓名、EMAIL、手機＋密碼）／新增差勤（預設今天 8:30–17:30）／每項費用拍照或「自動判斷類別」／多張收據自動加總／月份分組與小計／下載單月或全部月份 ZIP（xlsx＋`receipts/<月>/…jpg`）／管理者檢視、修正員工資料與差勤、收據、重設密碼。
